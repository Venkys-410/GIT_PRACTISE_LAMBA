For Git to recognise a branch, it should have atleast one commit.

.gitignore -- Add the names of the files to this file if we do not want to track them.

Git by default do not track empty directories. To track them create a .gitkeep file inside the empty directory.

git log --> To view the commit log
git log --oneline --> To view each commit in one line.

git branch --> shows all the branches. * will point the current branch on which we are.

git switch branchName --> switches to that branch
 
git switch -c "branchName" --> create a new branch if it does not exits. Switches to it if exists. 

git checkout "branchName" --> switches to that branch if exists.

git checkout -b "branchName" --> create a new branch if it does not exits. Switches to it if exists. 




Stashing:
Command	                     Purpose
git stash	                  Temporarily saves tracked file changes
git stash -u	               Saves changes, including untracked files
git stash list	               Lists all stashes
git stash pop	               Applies the latest stash and removes it from the stash list
git stash apply	            Applies the latest stash but keeps it in the stash list
git stash apply "stash@{n}"   Applies the n th stash from the stack
git stash drop	               Deletes the latest stash
git stash drop "stash@{n}"    Deletes the nth stash in the stack
git stash clear	            Deletes all stashes
git stash show -p	            Shows the changes stored in the latest stash

Command	                                 What it shows
git fetch origin	                        Downloads remote updates
git diff main origin/main	               Shows file-content differences
git log main..origin/main --oneline	      Shows commits present remotely but missing locally
git log origin/main..main --oneline	      Shows commits present locally but missing remotely
git status -sb	                           Shows your current branch's ahead/behind status, if its tracking information is configured
